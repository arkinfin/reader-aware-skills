## C. 机制判断

1. **Rigor 是否主要改善正确性？** 本轮未显示。基线已高度正确；实验 R 是单次生成内的严谨性指导，不等同于原 Skill 的完整审查工作流。
2. **Readability 是否独立改善可理解性？** 本轮未证实稳定增益。唯一控制局部优势不足以支持一般结论。
3. **是否互补？** 数学整体评分交互差异为零；一次 B/D 配对偏好仅是局部线索。
4. **是否相互干扰？** 未观察到系统性理解损害，但 C 仍出现一处方法建议泛化过强的轻微错误，不能把可读性指导当正确性保证。
5. **是否跨领域有效？** 控制仅一处局部差异，ML 为零，尚无一致泛化信号。
6. **是否存在代价？** C 每次调用增加约 716–718 个报告输入 token。A/C 平均汉字数：数学 449.7/456.0，控制 534.5/532.2，ML 592.3/616.0；ML 约增加 4%，没有整体评分收益。主评全部冗余评分为 1，也可能受评价分辨率限制。耗时受并行调度、缓存和平台影响；订阅 token 不是 API 账单。

没有依据把本次零差异归因于 Skill 本身无效，也没有依据宣称有效。没有观察到的错误类比、表面润色收益或机制冲突，不被编造成案例。实验后没有对新 Skill 追加题型专属规则。

## D. 实验局限

- 样本和任务有限；评分为序数，同一评价包内相关，描述性均值不是充分验证的总体因果效应。
- 同模型家族生成与评价可能偏好自身风格；独立上下文不等于独立模型或人类验证。
- 素材包含充分事实、定义和限制，基线已能写出较完整解释，可能压缩干预差异。
- 评分严重饱和；54/60 文本的汉字代理计数低于软目标 600，实际内容也短于预期，不能泛化到整章持续阅读。
- 平台仍注入相同全局目录和工作规则；两个目标 Skill 不在自动目录中，实际工具调用被禁止。这个共同背景已披露，不能声称实验运行于无背景的裸模型。
- 五小时额度未被当作可观测账单；没有降低模型、更换条件或调用新的收费外部服务。
- 尚未测量真实理解、记忆、迁移或学习增益，不同模型和任务可能表现不同。
