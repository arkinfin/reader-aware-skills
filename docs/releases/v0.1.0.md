# v0.1.0 — Initial experimental release

Two independently selectable skills for technical explanations and teaching:

- **reader-aware-writing**: self-contained guidance on reader knowledge,
  conceptual connections, information order and cognitive load.
- **pedagogical-readability**: the original teaching quality-control skill,
  preserving its existing shared-workflow dependency. That runtime is not bundled
  and currently has no public download location.

Small-scale informal review feedback reported by the maintainer has been
positive. No standardized questionnaire results or controlled learning outcomes
are available for this feedback. This is qualitative feedback, not a measured learning or treatment
effect; no survey is required to use the skills or offer feedback.

The included exploratory automated evaluation did not establish a consistent
comprehensibility benefit: 46 of 48 paired comparisons tied, and 59 of 60 overall
ratings were at the maximum. The original outputs, blinded judgments, disputed
error flags, limitations and offline replay are included unchanged.

MIT-licensed skill content. Installation instructions and examples are in the
README. This prerelease shares an experimental tool; it does not claim validated
learning gains, factual-accuracy guarantees or universal agent compatibility.
